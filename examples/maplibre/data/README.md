# MapLibre Sample Data

`real-roadworks.geojson` is a small, static excerpt from the public Autobahn-App API, fetched on 2026-07-05.

The file intentionally keeps only a handful of A8/A9 roadworks and simplified line geometries. It is meant for the GitHub Pages demo at `/Mobilithek/examples/maplibre/`, not as a complete mirror of the upstream feed.

`sample-events.geojson` remains a synthetic fallback fixture for tests and local experiments.
